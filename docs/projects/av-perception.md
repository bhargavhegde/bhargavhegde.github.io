## Overview

This ongoing research project focuses on developing a real-time 3D object detection system for autonomous vehicles. The system uses a CenterPoint-based algorithm integrated with Ouster LiDAR sensors to achieve high accuracy and efficiency in dynamic driving environments.

## Key Features

- 🎯 **CenterPoint-based Detection** - State-of-the-art 3D object detection algorithm
- ⚡ **Real-time Processing** - Optimized for low-latency inference
- 🔍 **High Accuracy** - Precise detection in dynamic environments
- 📡 **Ouster LiDAR Integration** - Direct integration with Ouster LiDAR sensors
- 🚗 **Autonomous Vehicle Focus** - Designed for real-world AV applications
- 🔬 **Research Project** - Part of CAVAS Lab research initiatives

## Technologies

- **Deep Learning**: PyTorch
- **Hardware Acceleration**: CUDA
- **Robotics Framework**: ROS2
- **Sensor**: Ouster LiDAR
- **Language**: Python, C++

## Research Context

This project is part of ongoing research at the **CAVAS Lab** (Connected and Autonomous Vehicle Applications and Systems) at the State University of New York at Buffalo. The research focuses on:

- Real-time 3D perception for autonomous vehicles
- LiDAR-based point cloud processing
- Integration with V2X communication systems
- Performance optimization for edge deployment

## Technical Approach

### CenterPoint Architecture
- Anchor-free 3D object detection
- Center-based keypoint detection
- Efficient feature extraction from point clouds

### LiDAR Integration
- Direct processing of Ouster LiDAR point clouds
- Real-time point cloud registration
- Multi-frame temporal fusion

### ROS2 Integration
- Modular architecture with ROS2 nodes
- Real-time data streaming
- Integration with AV software stack
