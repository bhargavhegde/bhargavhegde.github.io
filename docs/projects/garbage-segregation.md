## Overview

The Garbage Segregation System is an innovative robotic solution that automatically classifies and segregates different types of waste using computer vision and deep learning. The system combines YOLOv3 object detection with CNN-based classification to achieve high accuracy in waste identification, followed by automated pickup and placement using a robotic arm.

## Key Achievements

- ✅ **90% accuracy** in garbage classification
- ✅ **Secured funding** from Karnataka State Council for Science and Technology (KSCST)
- ✅ **Automated robotic arm** for pickup and placement
- ✅ **Real-time processing** on Raspberry Pi

## Technologies

- **Computer Vision**: YOLOv3, CNN
- **Hardware**: Raspberry Pi, Robotic Arm

## Features

- **Real-time Object Detection**: YOLOv3 for identifying garbage items
- **Deep Learning Classification**: CNN-based classification for waste categories
- **Automated Robotic Arm**: Pickup and placement of segregated items
- **Raspberry Pi Deployment**: Edge computing for real-time processing
- **Multi-category Classification**: Handles various types of waste materials

## Project Details

### Architecture

The system consists of:
1. **Vision Module**: Camera captures images of garbage items
2. **Detection Module**: YOLOv3 identifies waste items in the frame
3. **Classification Module**: CNN classifies items into waste categories
4. **Control Module**: Robotic arm executes pickup and placement
5. **Raspberry Pi**: Edge device for real-time processing

### Performance

- **Classification Accuracy**: 90% across multiple waste categories
- **Processing Speed**: Real-time detection and classification
- **Robotic Arm Precision**: Accurate pickup and placement
